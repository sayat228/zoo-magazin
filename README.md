# 🐾 ЗооМир - Магазин животных

Интернет-магазин по аренде и продаже домашних животных.

## 🚀 Быстрый запуск

### Способ 1: Простой запуск
1. Скачай файлы проекта
2. Открой index.html в браузере
3. Готово!

### Способ 2: Через Live Server (рекомендуется)
```bash
# Установи Live Server если нет
npm install -g live-server

# Запусти проект
live-server
📦 Зависимости

Проект использует:

· Font Awesome 6.0 (подключается автоматически)
· Современный браузер с поддержкой ES6+

🛠 Установка

1. Клонируй репозиторий:
git clone https://github.com/sayat228/zoo-magazin.git
1. Перейди в папку проекта:
cd zoo-magazin
1. Запусти:

· Либо открой index.html в браузере
· Либо используй Live Server для разработки
